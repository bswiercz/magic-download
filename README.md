# magic-download

Magically download videos, that need some extra permissions

## Usage

### Download a video

- Run `run.py` with session cookie and url as params
```
usage: run.py [-h] [--only-subs] url session
```

### Download only subs for a video
- run with `--only-subs` param

### Batch usage

1. Fill `run.sh` with links to videos
2. `./run.sh`
